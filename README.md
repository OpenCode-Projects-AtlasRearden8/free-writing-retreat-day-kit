# Free-Writing-Retreat-Day Kit

A free printable kit for running an **at-home Saturday writing retreat** —
timers, snacks, and gentle structure included. Explained like a friend would:
plain English, step by step, never condescending.

Built and maintained by **Asdale Dynamics, LLC** (Dylan Asdale's small
company for beginner-friendly books, guides, and practical tools).

## What's inside

Six printables, each available as a **Markdown source** (in `printables/`)
and a **print-ready HTML page** (in `print/`):

1. **Retreat-day schedule** — a full Saturday plan with alternating writing
   sprints and breaks, from 9:00 settle-in to a 5:00 reflection wind-down.
2. **Warm-up prompts** — 20 prompts in four tiers (quick-and-easy,
   story-starter, real-life, author-brain).
3. **Goal-setting one-pager** — one main goal, pre-set fallbacks, and a
   sprint tracker.
4. **Snack & hydration tent cards** — four fold-and-stand desk reminders
   ("Water first, words second." / "You can stop. The timer says so.").
5. **End-of-day reflection sheet** — three questions, keep/change/drop, and
   tomorrow's first line.
6. **Invite-one-friend planner** — a zero-drama, copy-paste-invite plan for
   bringing exactly one friend.

Plus a friendly host guide in `docs/retreat-guide.md`.

## How to run / print

No installation, no accounts, no data collection — it's just files.

- **Print:** open `print/index.html` in any browser and print the page you
  want (or open a printable directly). Styled for US Letter; A4 works too.
  The schedule prints best in landscape.
- **Markdown:** read/edit any file in `printables/` or `docs/`.
- **Verify:** run `python3 tests/verify.py` to check the kit's files,
  HTML structure, and privacy guarantees.

## Privacy

This kit collects nothing, tracks nothing, and stores nothing. No accounts,
no forms, no analytics — hand it to a friend and they need only a printer.
