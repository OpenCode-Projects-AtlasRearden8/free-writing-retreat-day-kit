# Printable: Snack and Hydration Tent Cards

> Print, cut along the line, fold at the fold mark, and stand them up where
> you write. They say things your afternoon brain needs to hear at 2 p.m.

These are fold-and-stand cards: print the HTML version, cut along the solid
lines, fold along the dashed lines, and each card becomes a tiny standing
sign. No tape needed - the fold does the work.

---

## Centet Card 1

```
        ___________________________________________________________________
       |                                                                   |
 FRONT |   WATER FIRST, WORDS SECOND.                                      |
       |   You have been typing, not drinking. RU OK?                      |
       |                                                                   |
       |   --> One big sip right now. Right now.                           |
       |___________________________________________________________________|
```

**FRONT:** WATER FIRST, WORDS SECOND.
You have been typing, not drinking. One big sip right now.

**BACK:** Coaches note: A hydrated author writes 0% more plot holes than a
dehydrated one. This is one of the few scientific facts in this kit.

## Tent Card 2

```
       |                                                                   |
 FRONT |   SNACK O'CLOCK (10:30 and 2:05 breaks)                           |
       |   Go get something with actual food in it.                        |
       |   Not "the last two inches of a bag."                             |
       |   A plate. A real snack. Then back.                               |
       |___________________________________________________________________|
```

**FRONT:** SNACK O'CLOCK. Go get a real snack, on a real plate.

**BACK:** Reasons this is not procrastination: 1) It's on the schedule.
2) Scheduled snack breaks are part of the retreat. 3) see item 1.

## Tent Card 3

```
       |                                                                   |
 FRONT |   SPRINT IN PROGRESS                                              |
       |   No, you cannot help me find the remote.                         |
       |   If you are me, the answer is "keep writing."                    |
       |   Ends :55 / :30 / :05. Water at every break.                     |
       |___________________________________________________________________|
```

**FRONT:** SPRINT IN PROGRESS. (Point at it instead of explaining yourself.)

**BACK:** buddy mode: If a friend is retreating beside you, this card
replaces all conversation. Nod at the card. Nod back. Perfect.

## Tent Card 4

```
       |                                                                   |
 FRONT |   YOU CAN STOP. THE TIMER SAYS SO.                                |
       |   Stopping is part of the plan, not a failure of it.              |
       |   Stand up. Stretch. The sentence will still be here.             |
       |___________________________________________________________________|
```

**FRONT:** YOU CAN STOP. THE TIMER SAYS SO.
Stopping is part of the plan, not a failure of it.

**BACK:** Reminder for afternoon-brain: "Pushing through" is how two
Sundays get lost. The schedule already gave you a rest. Take it.

## Make more cards

Want extra cards? Write your own on card stock with a fat marker. Ideas:
"I ALREADY DECIDED: the goal one-pager has the answer." / "Sitting ≠ writing.
(Type one line. See? Still easy? Keep going.)" / "The internet will still be
insufferable after 12:15." Keep the stack next to the snacks.
